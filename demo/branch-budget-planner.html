Adding lines — sub-headers come only from the Finance master

  • + line on a header opens a picker containing only the sub-headers defined under that header. A sub-header can never be typed: free text would invent sub-heads the master does not have, and coverage matches budget lines to sub-heads by name, so an invented one would silently never be counted.
  • The Sub-header column is a label everywhere in the grid, not an input. Only Detail — the item or contract description — is free text.
  • Unit and default sharing method come from the chosen sub-head's own master record.

Row actions

  • + on a row adds another detail line for that same sub-head — one sub-head can carry as many detail lines as the branch needs (two AMC contracts, three separate hire agreements).
  • ⧉ duplicates a detail line with its figures, for near-identical items.
  • ⌫ clears a line back to blank, which returns the sub-head to not planned.
  • ✕ deletes an added detail line. The first line of each sub-head cannot be deleted — all 38 come from the Finance master and every one has to be decided before submit — so it clears instead.
  • A row with unsaved edits shows an amber dot next to its name. Esc reverts the cell you are in; Ctrl+Z undoes the last change.

Why there is no per-row Save button

  • The budget is saved as one document — the API replaces the whole line set in a single transaction, so a per-row save would be a lie about what happens. Instead every edit is captured immediately, the toolbar tells you the state, and one Save draft commits the sheet. Row-level Undo and Clear give you the control a per-row save was reaching for.

How the arithmetic runs

  • ↓ Top-down — you type the branch Amount; cost-centre cells are derived. Manpower, Agent headcount, Revenue, Equal, Grade-weighted, Seats, Floor area, Devices, Hiring volume.
  • ↓ Manual — you type amounts per cost centre against the branch total; Unallocated must reach zero.
  • ↑ Direct and Meter — you type per-cost-centre cells and the branch Amount is the sum. Metered rows use your own projected units × the tariff; meter readings are historical and never gate a budget.
  • Splits allocate in whole rupees by largest remainder, so every column you can see adds up exactly.
  • Keyboard: Tab / Enter / arrows move, Ctrl+D fills down, and a block copied from Excel pastes straight in.
